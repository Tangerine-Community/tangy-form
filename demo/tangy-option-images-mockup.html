Option images: image on top, image fills the block

Static mockup of the proposed image-display="top|fill" attribute. The live inputs are in tangy-option-layouts.html, sections 9-12. Tap any option to select it (green border, today's colour). Dashed boxes are 360px wide, a phone screen. Pictures are placeholders.

D · Markup: today's markup, plus one attribute

Everything except the highlighted part exists today. layout and checkbox <option image> come from the feature/option-layout branch (built, uncommitted). image-display is the only new thing. Leave it off and nothing changes: the image stays beside the text.

<tangy-radio-blocks name="status" label="Status" layout="squares" image-display="top">
  <option value="1" image="./assets/present.svg">Present</option>
  <option value="2" image="./assets/absent.svg">Absent</option>
  <option value="3" image="./assets/left-early.svg">Left early</option>
</tangy-radio-blocks>

<tangy-radio-blocks name="transport" label="How did you come to school today?" layout="fit" image-display="fill">
  <option value="walk" image="./assets/walk.jpg">Walked</option>
  ...
</tangy-radio-blocks>

<tangy-checkboxes name="breakfast" label="What did you eat this morning?" layout="squares" image-display="fill">
  <option value="porridge" image="./assets/porridge.jpg">Porridge</option>
  ...
</tangy-checkboxes>
  • image-display values: top, fill. Missing or empty = today's look.
  • On tangy-radio-blocks and tangy-checkboxes only (radio buttons take no image).
  • Saved data does not change: the value is still the option value.
  • In fill, an option with no image shows its text, so a tile is never blank.
